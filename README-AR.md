# نسخة NeoFreeBird المعدّلة

التعديل: خيار LTR يغيّر اتجاه عناصر الواجهة ويترك اتجاه نصوص التغريدات الطبيعي، بما فيه العربية RTL.

## دمج نسخة Twitter/X أحدث على Windows

1. افتح `Build-IPA.cmd` بنقرتين.
2. اختر نسخة Twitter/X مفكوكة التشفير بصيغة IPA. يمكنك حفظها مسبقًا داخل `input`.
3. انتظر حتى يكتمل الدمج. ستجد الناتج في `outputs` باسم إصدار التطبيق.
4. افتح الناتج في Sideloadly لتوقيعه بحسابك وتثبيته على الهاتف.
5. فعّل خيار تخطيط الواجهة من اليسار إلى اليمين داخل إعدادات الأداة وأعد تشغيل التطبيق.

يمكنك أيضًا سحب IPA على `Build-IPA.cmd`، أو استخدام:

```powershell
.\Build-IPA.ps1 -IPA 'C:\path\Twitter-decrypted.ipa' -Output 'C:\path\Twitter-modified.ipa'
```

تتضمن هذه النسخة Python وLIEF محليًا؛ لا تحتاج تثبيتهما أو الاتصال بالإنترنت لإعادة الدمج.
الملف الأصلي لا يتغيّر. إذا كان اسم الناتج موجودًا، حدّد اسمًا آخر أو انقل الناتج السابق.

## ما الذي يُعاد استخدامه؟

`prebuilt/sideload` يحتوي مكتبات الأداة التي بُنيت واختُبرت مع Twitter 12.42.1، ومواردها ورقم commit وبصمات SHA256.
`vendor/CydiaSubstrate.framework` يحتوي إطار الربط وتراخيصه.
تغيير IPA يعيد دمج هذه المكتبات؛ لا يعيد تجميع كود Objective-C. تعديل كود الأداة يتطلب بناء مكتبات جديدة وتحديث هذه الملفات وبصماتها.
قد تغيّر إصدارات Twitter/X المستقبلية الواجهات الداخلية؛ نجاح الدمج لا يضمن توافق كل ميزة دون اختبار على الهاتف.

## حزم الجيلبريك

- `iphoneos-arm`: نظام Rootful، وليس دعم أجهزة ARM ذات 32 بت.
- `iphoneos-arm64`: نظام Rootless.
- المكتبات في الحزمتين تُبنى لـ arm64 وarm64e، والحد الأدنى للنظام iOS 15.
- دعم arm64e في المكتبة لا يعني حزمة خاصة بـ Roothide؛ Roothide ليس هدفًا لهذا البناء.

حزم DEB مخصصة للجيلبريك ولا تُثبَّت عبر Sideloadly. استخدم IPA للتثبيت عبر Sideloadly.

## إعادة البناء من المصدر

توجد إعدادات GitHub Actions في `.github/workflows`. يوفر `universal-debs.yml` بناء الحزمتين، و`ltr-test.yml` بناء مكتبات Sideload.
عند نقل المشروع لمستودع آخر، يمكن تشغيل `workflow_dispatch` بعد وضع ملف workflow على الفرع الافتراضي وتمكين Actions.
على macOS مع Theos وXcode: حدّث submodules ثم استخدم إعدادات البناء في workflows.
لا ترفع IPA أو مجلد `.tools` أو المخرجات إلى Git.
